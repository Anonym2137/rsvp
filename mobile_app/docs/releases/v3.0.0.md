# RSVP Reader 3.0.0

RSVP Reader 3.0 brings a redesigned mobile interface with violet, mint, and amber accents in light and dark themes.

- Gluestack UI across all five tabs, the full-screen reader, import dialogs, book actions, and sharing sheets.
- Weekly reading activity chart from saved sessions, reading-time summary, and clearer statistics.
- Lottie loading, empty-state, and completion animations with reduced-motion fallbacks.
- Correct dark backgrounds around rounded navbar corners and improved text wrapping on narrow screens.
- English and Polish interface translations.
- Existing books, progress, ratings, preferences, imports, and sharing remain supported without a data migration.

Android version 3.0.0, version code 4. Signed with the existing release key.
